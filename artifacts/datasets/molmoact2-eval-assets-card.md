# IMPRINT RMBench MolmoAct2 Evaluation Assets

This compact dataset contains only the evaluation metadata and stored Pi0.5
language embeddings needed to reproduce the MolmoAct2 RMBench rollouts.

DINOv3 and Qwen are downloaded directly from their upstream Hugging Face
repositories at the revisions recorded in `manifest.json`. No simulator,
optimizer state, source archive, or offline visual feature arrays are included.
